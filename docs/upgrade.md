This lite pack is one effect (fireball explosion). The full **Explosion VFX** pack
is the same system with six blasts and the full texture set.

| | Lite (this) | Explosion VFX |
|---|---|---|
| Effects | 1 (fireball) | 6 (fireball, debris, plasma, shockwave, smoke, spark shower) |
| Shape textures | 3 | 9 |
| System (shaders, ring, sparks, light) | ✓ | ✓ |

Installs alongside the full pack without clashing. Lite classes are
`FreeExplosionFx*`, full ones `ExplosionFx*`. On the same store account.
